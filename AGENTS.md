# Правила проекта `greek_sheets`

## 1. Завершение любой задачи — сборка, коммит и пуш
- После любых изменений в коде или контенте **всегда** в конце:
  1. Запустить `npm run build` и убедиться, что сборка проходит без ошибок.
  2. Сделать `git add -A`, создать осмысленный коммит (`git commit -m "..."`) и запушить в `origin main` (`git push origin main`), чтобы GitHub Actions автоматически обновил сайт на GitHub Pages.

## 2. Контент тем (`src/topics/`) и уроков (`src/lessons/`)
- Все тематические страницы и уроки начинаются с раздела глаголов (`id: 'verbs'`).
- Каждый глагол из раздела `verbs` должен присутствовать в словаре спряжений (`src/verbs/`) для работы карточки с 3D-кубом.
- Даты уроков всегда указывать с годом в формате `DD.MM.YYYY` (например, `20.11.2026`).
- В уроках указывать связанные темы (`relatedTopics`), а профильные новые слова из урока, которых ещё нет в соответствующей теме, добавлять и в тематический лист (непрофильную грамматику оставлять только в уроке).

## 3. UI и дизайн
- Сохранять минималистичный интерфейс без лишних поясняющих текстов — контент должен начинаться сразу на первом экране на телефоне и десктопе.
- Поиск, фильтры, режимы скрытия и навигацию по разделам держать в выпадающем меню (`#tools-menu`), не загромождая страницу.
