# Greek Sheets (`Ελληνικά · A1–A2`)

Минималистичные тематические листы (шпаргалки) со словами и фразами на новогреческом языке уровня **A1–A2** для подготовки к экзаменам (*Ελληνομάθεια*) и разговорной практики.

## Что внутри

- **Навигационная страница** (`index.html`) со списком всех тем.
- **Тематические страницы**:
  - **Дом и предметы быта** (`src/topics/home.ts`) — комнаты, мебель, техника, прилагательные и повседневные фразы.
  - **Расположение и движение** (`src/topics/location.ts`) — предлоги места, направления, глаголы движения и фразы для ориентирования.
- **Инструменты на каждой странице**:
  - поиск по греческим (можно без ударений) и русским словам;
  - фильтр по уровню (`Все` / `A1` / `A2`);
  - режим самопроверки («Скрыть греческий» / «Скрыть перевод» с открытием карточек по клику);
  - озвучка произношения (`el-GR` через Web Speech API);
  - аккуратная версия для печати / PDF.

## Локальный запуск 

```bash
npm install
npm run build
npm run preview
```

## Как добавить новую тему

1. Создайте файл в `src/topics/<slug>.ts` (по образцу `src/topics/home.ts`).
2. Добавьте экспортированную тему в массив `topics` в `src/topics/index.ts`.
3. Выполните `npm run build` (или просто запушьте в `main` — GitHub Actions соберёт и обновит сайт автоматически).

## Публикация на GitHub Pages

Деплой настроен через [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) при каждом пуше в ветку `main`.
В настройках репозитория на GitHub откройте **Settings → Pages → Build and deployment → Source** и выберите **GitHub Actions**.
