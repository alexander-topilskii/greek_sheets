# Greek Sheets (`Ελληνικά · A1–A2`)

Минималистичное офлайн-приложение (PWA) и тематические листы со словами, глаголами, фразами и мини-диалогами на новогреческом языке уровня **A1–A2** для подготовки к экзаменам (*Ελληνομάθεια*) и живого общения.

## Что внутри

- **24 тематические страницы** (~1400+ слов и фраз), каждая начинается с раздела глаголов, содержит грамматическую памятку (`Σημείωση`) и **мини-диалог** с озвучкой.
- **Карточка спряжения глаголов с 3D-кубом** (220 глаголов): клик по любому глаголу открывает все времена (`Παρελθόν`, `Ενεστώτας`, `Μέλλοντας`), повелительное наклонение и причастия для всех 6 лиц со свайп-вращением куба и озвучкой каждой формы.
- **Режим «Повторить»**: флеш-карточки (русский → клик → греческий с озвучкой).
- **Инструменты обучения**: глобальный поиск по всем темам (включая ввод без ударений), избранное (`☆ / ★`), фильтр `A1 / A2`, режим самопроверки («Скрыть греческий / перевод»), светлая и тёмная темы, версия для печати.
- **Установка на телефон (PWA)**: `manifest.webmanifest`, иконки и `sw.js` для офлайн-доступа на iOS и Android.

## Локальный запуск

```bash
npm install
npm run build
npm run preview
```

## Как добавить новую тему

1. Создайте файл в `src/topics/<slug>.ts` и добавьте диалог в `src/topics/dialogues.ts`.
2. Зарегистрируйте тему в `src/topics/index.ts` (и при необходимости добавьте новые глаголы в `src/verbs/`).
3. Выполните `npm run build` или запушьте в `main` — GitHub Actions соберёт и обновит сайт автоматически.

## Публикация на GitHub Pages

Деплой настроен через [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) при пуше в ветку `main`.
В настройках репозитория на GitHub откройте **Settings → Pages → Build and deployment → Source** и выберите **GitHub Actions**.
